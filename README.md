# AG Neovo City Select

版本：**1.1.0** · [原始碼](https://github.com/jasonwang-tw/AG-Neovo-City-Select) · [版本紀錄](CHANGELOG.md)

台灣 WooCommerce 傳統結帳、會員地址與購物車運費計算的縣市／鄉鎮及郵遞區號連動。使用者於 2026-11-19 同意建立自製外掛，保留既有外觀、欄位及 3 碼帶入，並處理 SAP 對 RY 字典的相依。詳細範圍及驗收見 PLAN.md，UI 選型與已確認需求見 DOC.md。

## 執行環境

WordPress、WooCommerce 傳統 shortcode、Polylang、PHP 8.2+；前端沿用站上 WooCommerce 的 jQuery／SelectWoo。無 npm、打包步驟、外部 API 或新 CSS 框架；新增唯讀管理頁，結帳版型維持原樣。

- 370 筆台灣地區／郵政選項及 22 個英文縣市 key，包含中英文名稱與 3 碼郵遞區號。370 並非純行政區數（含東沙／南沙郵政選項）。
- 保留 billing／shipping／calc_shipping 的既有欄位名稱，維持 Checkout Field Editor 與主題樣式相容。
- 已存在的城市值及較精確郵遞區號在首次載入、AJAX 重繪時保留；使用者明確切換縣市／鄉鎮後，依新選項帶入 3 碼。切換縣市不擅自選第一個鄉鎮。
- 保留既有英／中文城市值，未知既有值保留顯示供使用者確認。非台灣地址維持文字輸入。
- 提供 `agneovo_city_select_normalize_taiwan_part()` 給 SAP 使用，獨立完成英文縣市／鄉鎮轉繁中，不需載入 RY 程式或翻譯檔。


## 後台管理頁（1.1.0）

入口：**WooCommerce → City Select**；外掛清單也提供「設定」連結。具 `manage_woocommerce` 權限者可查看。若 WooCommerce 缺少，頁面安全降級至「設定 → City Select」，限 `manage_options`。

- 運作資訊：顯示目前接管、RY 啟用而待命、缺少 WooCommerce 或掛鉤未載入的狀態。
- 套用範圍：傳統結帳帳單／收件、會員地址、購物車運費計算及 SAP 本地轉換。
- 地址資料：顯示資料版本、縣市／選項數及基本格式檢查結果。
- 地址測試：選擇縣市／鄉鎮，立即查看三碼郵遞區號及 SAP 中文地址，可重設。不讀會員／訂單、不儲存資料、不呼叫外部服務。
- 操作說明：提供實際流程驗收及回復 RY 的步驟；配送區與運費繼續使用 WooCommerce 設定。

本頁為唯讀管理與測試工具，沒有儲存按鈕，不提供配送規則、會員／訂單或外掛啟用狀態的修改。管理頁測試不能取代實際會員結帳與超商選店驗收。

## 啟用與回復

資料夾 `agneovo-city-select` 放在 `wp-content/plugins/`，啟用 AG Neovo City Select。RY City Select 仍啟用時，新版地址介面保持待命；資料正規化 API 可用，供相容性驗證。只有 RY 停用後，新版才接手地址欄位及前端資源。沒有額外開關或背景任務。

切換前先驗證資料、SAP、帳單／收件地址、既有地址載入、購物車 AJAX 及桌面／手機操作；使用者的既有登入會員操作另行驗收，不建立管理員工作階段或真實測試訂單。回復先重新啟用 RY，新版便退讓；停用新版前確認 SAP 的回退依賴。不要批次還原 active_plugins 或會員／訂單資料。

## 範圍限制

- 不修改歷史訂單／會員地址、物流配送區、離島排除、金流、發票或獨立退貨表單。
- 六碼自動判定、Checkout Block、其他國家地址列為後續，不在本版自動加入。
- 不複製 RY 的全球資料下載、REST 報表改寫或額外設定介面；本站目前只銷售與配送 TW。

## 維護與驗證

所有 PHP 檔執行 `php -l`，JS 執行 `node --check assets/city-select.js`。地址字典全量對照原 370 筆，測試初始化與 AJAX 不覆寫地址、明確切換時回填、帳單／收件分離、未知既有值及海外文字回退。SAP 使用公開範例測試，不送出真實訂單／發票／物流或 SAP API。

資料來源與授權見 data/README.md、LICENSE.txt。驗證腳本、備份、截圖放私有暫存目錄，不納入外掛或版本控制。

## 本版驗收狀態（2026-11-19）

程式、35 項 WordPress 相容性檢查、370 筆字典對照、SAP 既有測試及 25 項桌面／手機隔離互動測試已通過。隔離測試採原生 WooCommerce HTML 與現有 SelectWoo，非正式主題或登入會員結帳的完整驗收。

初次部署採新版啟用待命、RY 繼續提供前端。來源交付前最新讀回顯示 RY 已停用，新版已註冊地址欄位與前端資源 Hook。此狀態不代表實際會員結帳已驗收；會員地址儲存、購物車運費及超商選店仍待確認。操作過程不需刪除舊外掛或會員／訂單資料。

初次部署後曾讀回確認新版啟用待命、RY 啟用，以及 SAP 1.0.29；當時 23 項讀回檢查通過，商店／SAP 選項、配送區及結帳欄位與基準相同。資料庫的本次預期變更只有啟用清單加入新版。

若 RY 仍啟用，實際驗收時需要安排短暫切換：停用 RY（保留檔案）後，新版才會提供地址選單。用現有會員登入，檢查會員帳單／收件地址、購物車運費、結帳不同收件地址及超商選店；不要為驗證送出真實訂單。若有問題，重新啟用 RY 即回復舊介面。本次來源交付未修改外掛啟用狀態；以管理後台及即時讀回結果為準。


## 原始碼安裝

GitHub 儲存庫根目錄即為外掛根目錄。下載原始碼後，將資料夾命名為 `agneovo-city-select` 再放入 `wp-content/plugins/`；若使用 ZIP 安裝，ZIP 頂層也應使用此資料夾名稱。不要額外包一層同名目錄。

本版本只交付地址外掛；SAP 對接端的 1.0.29 修正屬於獨立的 AG Woo SAP Order Sync 外掛，不包含在此儲存庫。若在其他站點整合，請由 SAP 對接端以 `function_exists()` 檢查後呼叫上述正規化 API。其他訂單及外部傳送行為不由本外掛提供。

Git 工作副本及版本 metadata 應保留在非公開目錄；正式部署目錄僅同步外掛檔案。
